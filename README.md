# Mercadato - Registro de Marca

Sistema de generación de presupuestos para registro de marcas en Venezuela.

## Uso

1. Abre `index.html` en tu navegador
2. O despliega en GitHub Pages

## Despliegue en GitHub Pages

1. Sube todos los archivos de esta carpeta a un repositorio GitHub
2. Ve a **Settings > Pages**
3. Selecciona **Deploy from a branch**
4. Selecciona **main** y **/(root)**
5. Guarda y espera 2 minutos

## Características

- Clases NIZA (45 clases)
- Tipos de búsqueda: Fonética, Gráfica, Mixta
- Cálculo automático de presupuesto
- Guardado en Google Sheets
- Generación de PDF
- Diseño responsive

## Tecnologías

- React + Vite
- Tailwind CSS
- Google Apps Script
- Google Sheets
